# 🎄 Christmas Tree Shaker

Eine kleine Web App: Ein schüttelbarer Weihnachtsbaum — zieh ihn mit Maus, Finger,
Pfeiltasten oder dem Handy-Sensor hin und her, bis die Christbaumkugeln purzeln.

Features:

- Physik-basiertes Schwingen des Baums (Feder-Dämpfung)
- 12 Kugeln, die bei heftigem Schütteln abfallen, mit Gravitation fallen und aufprallen
- Kugeln einzeln anklicken, um sie zurückzuhängen (oder Button „Alle zurückhängen“)
- Schnee, funkelnder Stern und optionale Sound-Effekte (Web Audio)
- Responsiv, keine Abhängigkeiten — läuft direkt im Browser

## Nutzung

Einfach `index.html` im Browser öffnen — fertig.
